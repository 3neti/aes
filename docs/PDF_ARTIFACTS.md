# PDF Artifacts

The first PDF artifacts are generated by `App\Election\Support\SimplePdf` without external services or database state. They are supporting evidence only; paper ballots remain the legal source of truth.

## Current Layout

Generated PDFs now include:

- A shaded header band.
- A clear artifact title.
- An `Alternative Election System - Simulation Evidence Artifact` subtitle.
- Monospaced body lines for hashes, ballot IDs, and tally rows.
- A footer reminder that paper ballots remain the legal source of truth.

The renderer remains intentionally small and deterministic. It does not embed images, call external services, or require a database read model.

## Verification

Current automated checks assert that generated ballot and Election Return PDFs:

- Start with `%PDF-1.4`.
- Contain the expected ceremony title.
- Contain expected ballot/tally data.
- Contain the simulation evidence subtitle.
- Contain the paper-ballot source-of-truth footer.
- Register the Courier body font resource.

## Visual Render Checks

Poppler is required for PNG render verification with:

```bash
pdftoppm -png path/to/artifact.pdf output-prefix
```

Poppler was not available in the local scaffold environment when this slice was implemented, so visual PNG render verification remains pending for an environment with `pdftoppm` and `pdfinfo` installed.
